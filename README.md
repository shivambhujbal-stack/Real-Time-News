# Real-Time News Feed App

This is a fullstack real-time news feed application using React, Redux, Node.js, Express, MongoDB, WebSockets, Docker, and Kubernetes.

## Features
- Real-time news updates by category
- WebSocket-based live subscriptions
- MongoDB aggregation for trending topics
- Docker + Kubernetes deployable

## Commands
```bash
# Server
cd server
npm install
node index.js

# Client
cd client
npm install
npm start
```
